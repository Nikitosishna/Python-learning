# Martingale Simulation (Python)

## Описание
Этот проект моделирует стратегию Мартингейла на подбрасывании монеты.  
Игрок начинает с фиксированного капитала и минимальной ставки. После каждого проигрыша ставка удваивается, после выигрыша — возвращается к минимальной.

Игра продолжается до полной потери средств.

## Как работает стратегия
- Выпадает **heads** → игрок выигрывает и получает x2 от ставки  
- Выпадает **tails** → игрок проигрывает и увеличивает ставку в 2 раза  
- При достижении лимита ставки (`max_bet`) — ставка сбрасывается  
- Если денег не хватает на ставку — ставится весь оставшийся баланс  

## Функции

### `flip_coin()`
Возвращает случайный результат:
- `"heads"`
- `"tails"`

### `play_martingale(starting_funds, min_bet, max_bet)`
Запускает одну симуляцию игры.

**Параметры:**
- `starting_funds` — начальный капитал
- `min_bet` — минимальная ставка
- `max_bet` — максимальная ставка

**Возвращает:**
- количество шагов до полного проигрыша

### `simulate_martingale_for_n_games(starting_funds, min_bet, max_bet, n_games)`
Запускает несколько симуляций и считает средний результат.

**Возвращает:**
- среднее количество шагов до проигрыша

## Пример запуска

print(play_martingale(starting_funds=100, min_bet=1, max_bet=100))
